# Thoth

Thoth is a free, open, voice-first multilingual Faithful Servant from [elghaly](https://elghaly.dev). It helps Indian exporters, including small ones, reach and talk to US buyers in their own language.

There is no charge for anyone. The tool itself is free and open.

It is powered by Google Gemini, Gemini Live, and Google Cloud.

**Free for every exporter.**
